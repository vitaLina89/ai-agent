# Описание проекта базы знаний

## Выбранная вселенная

**Star Wars** (starwars.fandom.com)

Выбрана как популярная вселенная с богатой мифологией, гарантированно представленная в обучающих датасетах LLM.

## Принцип замены терминов

### Стратегия замены

Все ключевые термины заменены на вымышленные, сохраняя:
- **Логику мира**: отношения между персонажами, структура событий
- **Стиль повествования**: эпический космический жанр
- **Связность**: взаимосвязи между сущностями сохранены

### Категории замен

1. **Персонажи** (14 замен)
   - Главные герои: Luke Skywalker → Kael Starwind
   - Злодеи: Darth Vader → Xarn Velgor
   - Наставники: Yoda → Master Qylos

2. **Планеты** (8 замен)
   - Пустынная: Tatooine → Vexara Prime
   - Столичная: Coruscant → Metropolis Prime
   - Ледяная: Hoth → Frosthold

3. **Технологии** (6 замен)
   - Оружие: Lightsaber → Plasma Blade
   - Корабли: Millennium Falcon → Stardust Runner
   - Станции: Death Star → Void Core

4. **Концепции** (ключевые замены)
   - The Force → Synth Flux
   - Jedi → Flux Wardens
   - Sith → Void Lords
   - Dark Side → Void Aspect
   - Light Side → Radiant Aspect

5. **События** (6 замен)
   - Battle of Yavin → Battle of Helios
   - Order 66 → Protocol Omega

6. **Организации** (5 замен)
   - Galactic Empire → Cosmic Dominion
   - Rebel Alliance → Liberation Front
   - Galactic Republic → Stellar Alliance

## Методология создания замен

1. **Систематичность**: заменены все упоминания ключевых терминов
2. **Согласованность**: одни и те же сущности заменены одинаково во всех документах
3. **Читаемость**: новые названия звучат естественно в контексте
4. **Уникальность**: замены не перекрываются с известными терминами

- ✅ "Flux Wardens" (вместо "Jedi")

В документе `Darth_Vader.txt`:
- ✅ "Xarn Velgor" заменяет все упоминания "Darth Vader"
- ✅ "Void Lords" (вместо "Sith Lords")

## Валидация для RAG

### Почему это работает

1. **Невозможность угадывания**: LLM не знает термин "Xarn Velgor" из обучающей выборки
2. **Вынужденное использование RAG**: модель может ответить только на основе загруженных документов
3. **Реалистичность**: имитирует корпоративную базу знаний с уникальной терминологией

### Проверка

Чтобы проверить, что модель не использует предобученные знания:
- Спросить: "Кто такой Xarn Velgor?" - ответ должен быть только из базы
- Спросить: "Что такое Synth Flux?" - модель не знает этого из обучения
- Спросить про связи между замененными сущностями - только из документов

## Использование

База знаний готова для интеграции в RAG-пайплайн. Все документы:
- Очищены от HTML
- Имеют замененные термины
- Сохраняют логику и смысл
- Уникальны и не распознаются LLM из обучающей выборки
