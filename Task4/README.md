# Задание 4: RAG-бот с техниками промптинга

## Описание

RAG-бот (Retrieval-Augmented Generation) с применением продвинутых техник промптинга: **Few-shot** и **Chain-of-Thought** (CoT). Бот использует векторную базу знаний из Task3 для поиска релевантных фрагментов и формирует ответы с помощью LLM.

## Структура проекта

```
Task4/
├── rag_bot.py          # Основной скрипт RAG-бота
├── telegram_bot.py    # Telegram-бот для RAG-системы
├── requirements.txt    # Зависимости Python
├── README.md          # Документация
├── SETUP.md           # Инструкция по настройке API ключей
└── TELEGRAM_SETUP.md  # Инструкция по настройке Telegram-бота
```

## Возможности

### 1. RAG Pipeline

Бот реализует полный пайплайн RAG:

1. **Получение запроса** - принимает текстовый запрос пользователя
2. **Преобразование в эмбеддинг** - использует ту же модель (`all-mpnet-base-v2`), что и при построении индекса в Task3
3. **Поиск в векторной базе** - находит ближайшие чанки в ChromaDB
4. **Формирование промпта** - собирает контекст и применяет техники промптинга
5. **Генерация ответа** - отправляет промпт в LLM (OpenAI, YandexGPT или локальная модель)
6. **Возврат результата** - возвращает ответ с указанием источников

### 2. Техники промптинга

#### Few-shot Learning

Бот использует примеры правильных ответов для обучения модели отвечать в нужном формате:

```
Примеры правильных ответов:
- Вопрос: "Кто такой Kael Starwind?"
- Ответ: "Kael Starwind - это главный герой истории..."

Текущий вопрос:
- Вопрос: "Что такое Synth Flux?"
- Ответ: ...
```

#### Chain-of-Thought (CoT)

Бот использует пошаговое рассуждение для формирования ответа:

```
Процесс рассуждения:
1. Определи, какая информация нужна
2. Найди релевантные фрагменты в контексте
3. Сформируй связный ответ на основе найденной информации

Вопрос: ...
Ответ (с кратким обоснованием): ...
```

#### Комбинация техник

Бот может использовать обе техники одновременно для максимального качества ответов.

#### Вариант 1: OpenAI API (рекомендуется для демонстрации)

1. Зайдите на сайт [OpenAI Platform](https://platform.openai.com/)
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)

5. Скопируйте ключ (он показывается только один раз!)

**Установка ключа:**

```bash

# Windows (PowerShell)

# Или создайте файл .env в папке Task4:
# OPENAI_API_KEY=sk-...
```

**Важно:**
- OpenAI предоставляет бесплатные кредиты при регистрации (~$5)
- После их исчерпания используется платная подписка (от $5 в месяц)

- Один запрос RAG-бота обычно стоит $0.001-0.005 (1-5 центов)

**Альтернативы OpenAI:**

## Использование

### Базовое использование

```bash
python rag_bot.py
```

Затем введите вопросы в интерактивном режиме:

```
Вопрос: Кто такой Kael Starwind?
Ответ: Kael Starwind - это главный герой истории...

Вопрос: exit
```

### Параметры командной строки

```bash
# Использование OpenAI (по умолчанию)
python rag_bot.py --provider openai --model gpt-3.5-turbo

# Использование YandexGPT
python rag_bot.py --provider yandexgpt

# Использование локальной LLM
python rag_bot.py --provider local

# Отключение Few-shot
python rag_bot.py --no-few-shot

# Отключение Chain-of-Thought
python rag_bot.py --no-cot

# Один запрос (без интерактивного режима)
python rag_bot.py --query "Кто такой Kael Starwind?"

# Показать промпт (verbose режим)
python rag_bot.py --query "Что такое Synth Flux?" --verbose

# Изменить количество релевантных чанков
python rag_bot.py --top-k 5
```

### Использование в коде

```python
from rag_bot import RAGBot, RAGConfig

# Создание конфигурации
config = RAGConfig(
    llm_provider="openai",
    llm_model="gpt-3.5-turbo",
    use_few_shot=True,
    use_chain_of_thought=True,
    top_k=3
)

# Инициализация бота
bot = RAGBot(config)

# Запрос
result = bot.query("Кто такой Kael Starwind?")
print(result["answer"])
print(f"Источники: {result['sources']}")
```

## Архитектура

### Классы и компоненты

#### `RAGConfig`

Конфигурация бота:
- Пути к векторной базе и модели эмбеддингов
- Параметры поиска (top_k)
- Настройки LLM (провайдер, модель, температура)
- Включение/выключение техник промптинга

#### `RAGBot`

Основной класс бота:
- `retrieve_context()` - извлечение релевантных фрагментов
- `build_prompt()` - построение промпта с техниками
- `query()` - обработка запроса пользователя

#### `LLMProvider` и провайдеры

Базовый класс и реализации для разных LLM:
- `OpenAIProvider` - OpenAI GPT API
- `YandexGPTProvider` - YandexGPT API (требует настройки SDK)
- `LocalLLMProvider` - локальная LLM через Ollama

### Пайплайн обработки запроса

```
Пользовательский запрос
    ↓
[1] Преобразование в эмбеддинг (all-mpnet-base-v2)
    ↓
[2] Поиск в ChromaDB (top-k ближайших чанков)
    ↓
[3] Форматирование контекста
    ↓
[4] Построение промпта
    ├─ Few-shot примеры (если включено)
    ├─ Chain-of-Thought инструкции (если включено)
    └─ Контекст + Вопрос
    ↓
[5] Генерация ответа через LLM
    ↓
[6] Возврат результата + источники
```

## Техники промптинга - детали

### Few-shot Learning

**Цель:** Научить модель отвечать в правильном формате через примеры.

**Реализация:**
- Бот включает 1-2 примера правильных ответов в промпт
- Примеры показывают, как обрабатывать разные типы запросов
- Модель учится следовать формату примеров

**Преимущества:**
- Улучшает качество ответов
- Помогает модели понимать ожидаемый формат
- Эффективнее, чем просто инструкции

### Chain-of-Thought (CoT)

**Цель:** Заставить модель рассуждать пошагово перед ответом.

**Реализация:**
- Бот включает инструкции по пошаговому рассуждению
- Модель должна сначала проанализировать вопрос
- Затем найти релевантную информацию в контексте
- И только потом сформировать ответ

**Преимущества:**
- Улучшает логичность ответов
- Снижает галлюцинации
- Повышает точность на сложных вопросах

### Комбинация техник

Использование обеих техник одновременно дает максимальный эффект:
- Few-shot показывает правильный формат
- CoT обеспечивает логичное рассуждение
- Результат: более качественные и точные ответы

## Настройка

### Изменение количества релевантных чанков

По умолчанию бот использует `top_k=3`. Для более детальных ответов увеличьте:

```python
config = RAGConfig(top_k=5)  # Больше контекста
```

### Изменение модели LLM

```python
config = RAGConfig(
    llm_provider="openai",
    llm_model="gpt-4"  # Более мощная модель
)
```

### Отключение техник промптинга

```python
config = RAGConfig(
    use_few_shot=False,      # Без Few-shot
    use_chain_of_thought=False  # Без CoT
)
```

## Ограничения и рекомендации

### API ключи

- **OpenAI:** Требуется API ключ (платно, но недорого для экспериментов)
- **YandexGPT:** Требуется настройка Yandex Cloud SDK
- **Локальная LLM:** Требуется Ollama или другая локальная модель

### Производительность

- **Поиск в ChromaDB:** < 100 мс
- **Генерация ответа:** Зависит от LLM (OpenAI ~2-5 сек, локальная может быть медленнее)

### Токены и стоимость

- Few-shot и CoT увеличивают размер промпта (~500-1000 токенов)
- Это увеличивает стоимость использования API (OpenAI)
- Для экономии можно отключить одну из техник
