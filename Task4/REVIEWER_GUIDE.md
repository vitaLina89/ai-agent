## Проверка техник промптинга

### Few-shot Learning

Бот должен использовать примеры из базы знаний в промпте. Это видно в verbose режиме или по качеству ответов.

### Chain-of-Thought (CoT)

Бот должен показывать пошаговое рассуждение перед ответом:
- "Шаг 1: Определю, какая информация нужна..."
- "Шаг 2: Найду релевантные фрагменты..."
- "Шаг 3: Проанализирую информацию..."
- "Следовательно, мой ответ:..."

## Проверка качества ответов

### Критерии хорошего ответа:

1. ✅ Ответ основан на контексте из базы знаний
2. ✅ Указаны источники информации
3. ✅ Ответ на русском языке (или с минимальным смешением языков)
4. ✅ Используется пошаговое рассуждение (если включен CoT)
5. ✅ Для вопросов вне базы - корректное сообщение "не знаю"

### Проблемы, которые могут возникнуть:

- ⚠️ Модель смешивает языки (английский + русский) - это нормально для llama3.2
- ⚠️ Иногда модель генерирует информацию не из базы - это ограничение локальных моделей
- ⚠️ Ответы могут быть длинными - это нормально для CoT

## Логи и отладка

Логи бота выводятся в консоль. Для сохранения в файл:

```bash
python telegram_bot.py > bot.log 2>&1
```

Или используйте nohup:
```bash
nohup python telegram_bot.py > telegram_bot.log 2>&1 &
```
