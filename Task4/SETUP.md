# Быстрая настройка RAG-бота

## 🚀 Быстрый старт

### Шаг 1: Получить OpenAI API ключ (бесплатно для начала)

1. **Зайдите на** https://platform.openai.com/
2. **Зарегистрируйтесь** (можно через Google/GitHub)
3. **Перейдите в** https://platform.openai.com/api-keys
4. **Нажмите** "Create new secret key"
5. **Скопируйте ключ** (он показывается только один раз!)

### Шаг 2: Установить ключ

**Linux/Mac:**
```bash
export OPENAI_API_KEY="sk-ваш-ключ-здесь"
```

**Windows (PowerShell):**
```powershell
$env:OPENAI_API_KEY="sk-ваш-ключ-здесь"
```

**Windows (CMD):**
```cmd
set OPENAI_API_KEY=sk-ваш-ключ-здесь
```

**Или создайте файл `.env` в папке Task4:**
```bash
# .env
OPENAI_API_KEY=sk-ваш-ключ-здесь
```

### Шаг 3: Установить зависимости

```bash
cd Task4
pip install -r requirements.txt
```

### Шаг 4: Запустить бота

```bash
python rag_bot.py
```

## 💰 Стоимость OpenAI API

- **При регистрации:** ~$5 бесплатных кредитов
- **GPT-3.5-turbo:** ~$0.001 за 1000 токенов (очень дешево!)
- **Один запрос RAG-бота:** ~$0.001-0.005 (1-5 центов)
- **100 запросов:** ~$0.10-0.50 (10-50 центов)

**Вывод:** Для экспериментов и обучения бесплатных $5 хватит на тысячи запросов!

## 🆓 Бесплатные альтернативы

### Вариант 1: Ollama (локальные модели)

**Установка:**
```bash
# Скачайте с https://ollama.ai/
# Или установите через:
curl -fsSL https://ollama.ai/install.sh | sh
```

**Использование:**
```bash
# Загрузите модель
ollama pull llama2

# Запустите бота
python rag_bot.py --provider local
```

**Плюсы:**
- ✅ Полностью бесплатно
- ✅ Работает офлайн
- ✅ Нет лимитов

**Минусы:**
- ❌ Требует много памяти (8GB+ RAM)
- ❌ Может работать медленнее
- ❌ Качество может быть ниже GPT-3.5

### Вариант 2: Hugging Face Inference API

Некоторые модели доступны бесплатно через Hugging Face. Можно настроить провайдер для работы с ними.

### Вариант 3: Google Gemini (есть бесплатный tier)

Google предоставляет бесплатный доступ к Gemini API с лимитами.

## 🔍 Проверка API ключа

Чтобы проверить, правильно ли установлен ключ:

**Linux/Mac:**
```bash
echo $OPENAI_API_KEY
```

**Windows (PowerShell):**
```powershell
echo $env:OPENAI_API_KEY
```

Если ключ не пустой и начинается с `sk-`, всё в порядке!

## ❓ Часто задаваемые вопросы

### Q: Обязательно нужен OpenAI API ключ?

**A:** Нет! Можно использовать:
- Локальные модели через Ollama (бесплатно)
- YandexGPT (если доступен в вашем регионе)
- Другие API (Anthropic Claude, Google Gemini)

### Q: Сколько стоит использование?

**A:** 
- **OpenAI GPT-3.5-turbo:** ~$0.001 за запрос (очень дешево)
- **Ollama:** Бесплатно (требует ресурсы компьютера)
- **При регистрации OpenAI:** ~$5 бесплатных кредитов

### Q: Безопасно ли использовать API ключ?

**A:** 
- ✅ API ключ хранится только локально (в переменных окружения или .env)
- ✅ НЕ коммитьте `.env` в Git (добавьте в `.gitignore`)
- ✅ Не публикуйте ключ в открытом доступе

### Q: Можно ли использовать без API для тестирования?

**A:** Да, можно использовать локальные модели через Ollama:
```bash
python rag_bot.py --provider local
```

Или использовать демо-режим (только поиск без генерации ответов) - можно добавить в код.

### Q: Ключ не работает, что делать?

**A:** Проверьте:
1. Правильно ли скопирован ключ (начинается с `sk-`)
2. Установлена ли переменная окружения
3. Есть ли кредиты на аккаунте OpenAI
4. Не заблокирован ли API в вашем регионе (можно использовать VPN)
